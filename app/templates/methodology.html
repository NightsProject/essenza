Methodology

Research Question

Does additional fine-tuning improve a pretrained Transformer's ability to preserve important facts when summarizing text under maximum length limits of 10%, 20%, and 30% of the source?

Models

Baseline
Original google/flan-t5-small checkpoint without additional project-specific fine-tuning.
Fine-tuned
The same base checkpoint after additional fine-tuning on the project's compression-constrained examples.

Compression Limits

Maximum summary length as a percentage of source word count:

  • 10% — Extreme compression
  • 20% — High compression (default)
  • 30% — Moderate compression

These are ceilings, not exact targets. A summary may be shorter than the selected limit.

Prompt Format

Both models receive the same prompt template:

summarize to at most {{ max_compression_percent }}%: {{ source_text }}

Allowed max_compression_percent values: 10, 20, 30.

Generation Configuration

Input limit
512 tokens (matching notebook configuration). Inputs exceeding this are rejected with a clear error.
Output limit
128 generated tokens (notebook default).
Decoding
Deterministic: num_beams=4, do_sample=False for reproducible demonstrations.
Device
CUDA when available; otherwise CPU.

Metrics Reported

Metric Description
Source word count Words in the input text (whitespace-delimited)
Summary word count Words in the generated summary
Actual compression ratio Summary words ÷ Source words × 100
Cap compliance Whether actual ratio ≤ selected maximum threshold

Limitations

  • Outputs can exceed the requested word cap; the model is not constrained to obey it.
  • Automatic generation alone does not establish factual correctness.
  • Fact coverage and factual consistency require human annotation (performed in the research workflow, not this demo).
  • Very short source texts make extreme compression impractical; word-ratio measurements are sensitive to small word-count changes.

Evaluation (Research Workflow)

The formal evaluation pipeline remains in the Colab notebook:

  • Blind annotation of fact coverage and factual consistency
  • Bootstrap confidence intervals
  • ROUGE-L and other automated metrics
  • Statistical significance testing

This web application is for interactive demonstration and qualitative comparison only.
